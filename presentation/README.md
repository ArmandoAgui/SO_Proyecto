# Presentación ejecutiva

presentacion.tex produce 12 diapositivas en PDF con Beamer: problema, alcance,
arquitectura, estados, demos, consistencia, transporte, pruebas, reproducción y límites.

```sh
make docs
```

Abrir build/entrega/presentacion.pdf a pantalla completa. No requiere PowerPoint.
Los nombres son los proporcionados por el usuario; faltan apellidos, institución y
sección. La distribución de la exposición debe reflejar contribuciones reales.

Guion sugerido, 8–10 minutos: Armando introduce el problema; un Daniel explica la
arquitectura; Guillermo los estados y migración; el otro Daniel la invalidación;
Mauricio pruebas y límites. Es una sugerencia para repartir la presentación, no una
afirmación de quién escribió cada parte. Todos deben poder repetir y explicar la demo.
